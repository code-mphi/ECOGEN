◆ readInfos()

void Output::readInfos ( )

Currently only used for OutputBoundaryMassflowGNU.

Read the informations related to a previous simulation (number of cpu, time, file number, etc.) using infoCalcul file

Only the content since the file number to be resumed is kept (as the next files will overwrite the later content)

virtual void Output::readResults ( Mesh * ,
std::vector< Cell * > * ,
int = -1 )
inlinevirtual

Read results of a previous simulation to resume from it.

Available for all mesh types if the same number of cpus is used between both simulations

Parameters
meshMesh object of the current simulation in case of resume. Mesh object of a single partition of the previous simulation (either the same one as current or older one in case of mapping).
cellsLvlComputationnal cells to be filled with results of previous simulation
cpuIndex of cpu file to read if provided (meshMappingRestart case), otherwise, the file associated with current cpu rank is readed (simulation resume case)
