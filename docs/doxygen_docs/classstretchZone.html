Stretched zone constructor.

Stretched zone constructor: compute number of cells from mesh stretching area size,

Parameters
startAtposition of beginning of mesh stretching area
endAtposition of end of mesh stretching area
factormesh stretching factor: 1. means no stretching, value lower than 1. means mesh shrinking
refCellSizesize of reference cell to which mesh stretching factor is applied
refCellPosposition of the reference cell ('end' or 'start')

Recall:

  • geometric sequence is defined by:
    • \( u_{n+1} = u_n * q \)
    • \( u_n = u_0 * q^n \)
  • the sum is given by: \( sum_{k = 0}^{n} u_k = u_0 (1 - q^{n+1}) / (1 - q) \)
  • If we note l the length of the stretching area, we want:
    • \( u_0 = l = S_0 \) when we have only 1 cell in the stretching area.
    • i.e., \( Nc = n+1 \), with Nc the number of cells in the stretching area.
    • and \( l = S_{Nc-1} \).

In consequence, we have \( Nc = \frac{ ln(1-(1-q)*l/u_0) }{ ln(q) } \).
