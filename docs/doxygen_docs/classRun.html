◆ solver()

void Run::solver ( )

Hyperbolic resolution + Relaxations + Source terms integration.

Hyperbolic part is solved using Finite Volume method :

\[ \frac{U^{n+1}_i-U^{n}_i}{\Delta t} = -\sum_{faces} \vec{F}^*_f \cdot \vec{n}_f \]
