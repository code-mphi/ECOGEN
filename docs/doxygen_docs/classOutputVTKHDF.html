template<size_t N, typename T>
int OutputVTKHDF::writeArrayVTKHDF ( const hid_t & group_id,
const std::string & dataset_name,

const hsize_t(&) offsets[N],
const hsize_t(&) chunk_dims[N] ) const
protected

Write a N-dimensional array of C++ type T and hdf5 type hdf_type using parallel HDF5.

Implements a collective write operation where:

  • Each MPI rank writes the 'dataset' vector resized under the form of an array of rank N and dimensions 'local_dims'.
  • The resulting dataset spans all MPI ranks and is written in a region of rank N and size 'global_dims'
  • Size, position and offset of writing area are provided as argument Allow to write efficiently structured data and can be called by previous 'writeArrayVTKHDF' function.
Template Parameters
NRange in hdf5 memory and file of array to write
Parameters
group_idIdentifier of hdf5 object where data will be written
dataset_nameString containing the name of the VTKHDF dataset to write
hdf5_mem_dtypeHdf5 data type to use for storage and transfer: must match architecture (LE, BE) and the size of the data in memory (int32_t, int64_t..)
hdf5_file_dtypeHdf5 data type saved in file: hdf5 will manage the conversion from the hdf5_mem_dtype to this type if needed
parallel_x_propertiesProperty for raw data transfer (collective or independent - collective writes are unavailable if file is not open in parallel)
datasetPointer to the array to write
global_dimsglobal dimensions of array to write in file
local_dimslocal dimensions on the current MPI process of array to write in file
offsetsoffsets at which write the array in file
chunk_dimsWanted dimensions of file chunks (to optimize data access). If chunk_dims[0] is 0, chunking is disabled.
Returns
ERROR_VALUE if fail, SUCCESS_VALUE if success
Note
- Exceptions are not used to avoid the creation of a corrupted file

protected

Write a 2-dimensional array of an unstructured mesh using parallel HDF5.

Implements a collective write operation to dump arrays of unstructured data (so for unstructured and AMR meshes) where:

  • array has C++ type T and hdf5 type hdf_type
  • Each MPI rank writes its line_count lines of the array and all its columns
  • The resulting dataset spans all MPI ranks
  • Size, position and offset of writing area is locally computed using a collective call ('Allgather')
